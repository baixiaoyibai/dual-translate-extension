⚠ 免责声明

本插件仅作为翻译辅助工具，不对翻译结果的准确性、完整性或适用性负责。翻译结果由第三方翻译接口（百度、DeepSeek、智谱、火山引擎等）提供，插件不对第三方服务的可用性和翻译质量做任何保证。

对于重要内容的翻译（如法律文件、医疗信息、技术规范等），请以专业人工翻译为准。使用本插件即表示您理解并接受上述免责声明。

🔧 插件工作原理

1. 扫描网页：插件在网页加载后扫描页面中的文本段落（段落、标题、列表等），跳过代码块、脚本和样式内容。
2. 语言检测：检测文本语言，仅翻译英语和日语内容（可在设置中调整）。
3. 术语替换：将文本中的专业术语按术语库规则预处理。
4. 调用翻译接口：将文本批量发送到已配置的翻译接口，按优先级依次尝试。首个接口失败或额度不足时自动切换到下一个。
5. 注入译文：将翻译结果按所选显示模式（双语对照/仅译文/悬停翻译/对照面板）注入回页面。
6. 缓存：已翻译的文本会缓存 3 天，再次遇到相同内容时直接使用缓存，不重复调用 API。

🗃 API 管理页说明

「API 管理」标签页是插件的核心配置区域，统一管理所有翻译接口。页面包含两类接口：

一、机器翻译接口（按字符计费）
• 百度机器翻译：通用文本翻译，需填写 App ID + 密钥
• 百度大模型翻译：百度基于大模型的翻译接口，需填写 APP ID + API Key
• 火山引擎机器翻译：火山引擎旗下机器翻译服务，需填写 Access Key + Secret Key

二、大模型翻译接口（按 Token 计费）
• DeepSeek / 智谱 GLM（免费版）/ 通义千问 / 智谱 GLM（付费版）/ 零一万物 / 豆包：均通过 OpenAI 兼容 API 接入，需填写 API Key，部分可自定义模型名称和接口端点
• 自定义大模型：任何兼容 OpenAI 格式的接口均可接入，需填写 baseURL + API Key + 模型名称

页面功能：
• 启用/关闭：每个接口卡片可单独开关，关闭后不会被调用
• 测试按钮：填写密钥后可点击「测试」验证连通性
• 清除按钮：一键清除某个接口的所有配置信息
• 优先级排序：拖拽列表调整接口使用顺序，排在前面的优先使用
• 免费额度标注：每个接口旁显示该服务的免费额度信息

提示：机器翻译接口翻译速度快、成本低，适合日常浏览；大模型接口翻译质量更高，适合对翻译准确性要求较高的场景。建议两者搭配使用。

📊 额度限制功能说明

在「额度限制」标签页中，您可以为每个翻译接口设置每日或每月使用上限：

启用限制：勾选开关后，该接口的用量会被跟踪。
额度数值：填写允许使用的最大量。
计费单位：选择「字符」或「Token」。机器翻译接口（百度/火山引擎）按字符计费，大模型接口按 Token 计费。
重置周期：选择「每日」则每天 0 点重置用量统计；选择「每月」则每月 1 号重置。可根据接口的计费周期灵活选择。

当某接口用量达到设定额度的 97% 时，插件会自动按「API 管理」中的优先级排序切换到下一个翻译源，避免超额产生费用。

注意：Token 用量为估算值（1 Token ≈ 2 字符），实际计费以服务商账单为准。此功能仅为辅助提醒，不保证完全避免超额。

📖 术语库使用说明

术语库用于自定义特定词汇的翻译规则，支持全局和域名专属术语：

全局术语：在所有网站生效。适合通用的专业术语，如 tank → 坦克。
域名专属术语：仅在指定网站生效。可在术语管理页添加域名（如 *.example.com），为不同网站设置不同翻译规则。

匹配模式：
• 精确匹配：原文术语完全匹配时替换（推荐用于专有名词）。
• 模糊匹配：包含原文术语时替换（适合短语）。

保留原文：开启后，该术语不会被翻译，保持原文显示。适合缩写如 HP、MP、NPC 等。

术语库支持 JSON 格式的导入导出，方便备份和迁移。

🔑 密钥存储说明

所有 API 密钥仅保存在本地浏览器中（chrome.storage.local），不会跨设备同步到 Google/微软账户，也不会上传到任何服务器。

具体存储位置：
• 百度 App ID / 密钥 → 本地存储
• 百度大模型 APP ID / API Key → 本地存储
• 火山引擎 Access Key / Secret Key → 本地存储
• DeepSeek / 智谱 / 通义 / 零一 / 豆包 API Key → 本地存储
• 自定义大模型 API Key → 本地存储

PIN 码保护：API 密钥受 6 位 PIN 码保护，输入正确 PIN 码后才能查看和编辑密钥。连续 5 次输错将临时锁定，锁定状态在 Service Worker 重启后仍然有效。密钥在未解锁状态下以掩码形式显示（如 sk-12****78）。

导出设置时：导出的 JSON 文件不包含任何 API 密钥，仅包含显示设置、翻译规则、术语库等非敏感数据。换机迁移后需重新填写密钥。

清除密钥：在「API 管理」页面，每个接口卡片右侧有「清除」按钮，可一键删除该接口的所有配置信息。

如需彻底清除所有数据，可在浏览器扩展管理页面点击「清除数据」。

💻 开发说明

本插件是一个开源的个人项目，部分代码使用 Vibe Coding 方式编写——即通过 AI 辅助编程工具（如 Cursor、TRAE 等）以自然语言描述需求，由 AI 生成代码并经人工审查和调试。

什么是 Vibe Coding？
Vibe Coding 是一种新兴的编程范式，开发者通过自然语言向 AI 描述意图和逻辑，AI 生成对应的代码实现。开发者负责需求定义、架构设计、代码审查和质量把控，AI 负责具体的代码编写。这种方式能显著提升开发效率，尤其适合快速迭代的项目。

质量保障措施：
• 所有 AI 生成的代码均经过人工逐行审查
• 关键逻辑（签名算法、密钥存储、安全校验等）经多轮测试验证
• 已知问题在后续版本中持续修复和优化
• 代码遵循安全最佳实践（输入校验、XSS 防护、密钥隔离等）

开源与反馈：
本项目代码完全开源，欢迎在代码仓库中提交 Issue 或 Pull Request。如发现翻译异常、功能缺陷或有改进建议，请通过项目仓库的 Issue 页面反馈。

声明：Vibe Coding 生成的代码可能存在未预见的行为或边界情况。虽然已尽力测试和审查，但仍建议在使用重要内容翻译时以人工翻译为参考。
