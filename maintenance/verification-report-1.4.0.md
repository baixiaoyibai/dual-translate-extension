# v1.4.0 验证记录

验证日期为 2026-11-27，环境为 Windows、Node.js 24.16.0、Microsoft Edge 158.0.4370.33。

## 第一轮修复与验证

第一轮以已有代码和实际用户入口为基础，检查段落提取、动态页面、后台翻译及数据流。

- 将整段术语替换短路改为完整翻译后应用术语，单独的完整词条可直接命中。
- 使用文本节点分组，保留段内链接、强调和其他内联元素。过滤隐藏节点、表单、编辑区和禁止翻译区域。
- 增量监听子节点、文本与显隐属性变化，在翻译过程中保留待扫描状态。返回浏览器标签页时重新检查可读内容。
- 移除隔离环境中的 history 包装及原有指纹轮询，依靠 DOM 变化和页面可见性事件继续翻译。
- 通过后台消息下发页面设置，收紧 local/sync 访问范围。会话缓存替代磁盘翻译缓存，旧缓存启动时清理。
- 将入口整合为「翻译此页 / 还原此页」，总开关独立。新安装默认手动，已保存的自动翻译偏好在重新加载后保留。

实际加载扩展的 Edge 测试通过手动触发、CSS 选项卡显隐、动态新增、SPA 复用节点、滚动加载、切回浏览器标签和还原原文。

## 可复现命令

```bash
npm run verify
npm install --no-save --package-lock=false playwright-core
npm run test:edge
```

`npm run verify` 包含语法检查、已有回归和新增翻译管线测试。Edge 集成测试启用临时空浏览器配置，在本机监听模拟接口并路由合成网页。模拟凭据为固定测试字符串。

## 验证范围

以上测试验证扩展运行、数据范围、请求与响应处理，真实服务商的翻译质量、账户额度和生产 API 兼容性仍需使用相应账户验证。个人浏览器中的现有扩展需要在 Edge 扩展管理页重新加载，并刷新已有网页。

iframe、Shadow DOM、图片 OCR 和浏览器内部页面的翻译属于专门适配范围。可读网页正文中的个人信息会随主动翻译或已启用的自动翻译发送给所配置的服务，发送前可使用网站白名单和手动触发控制范围。
