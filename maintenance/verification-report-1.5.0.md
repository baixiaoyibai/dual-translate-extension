# v1.5.0 交互与运行开销验证

日期为 2026-11-27，使用 Windows、Node.js 24.16.0 和 Microsoft Edge 158.0.4370.33。

## 外观与操作

- 弹窗首屏集中显示当前网站、翻译/还原、阅读方式和语言。文本翻译、服务用量与缓存详情按需展开。
- 使用本地共享样式统一弹窗、设置与欢迎页的明暗主题、字体、颜色、间距和键盘焦点，跟随系统减少动画偏好。
- 弹窗直接读取 manifest 显示 v1.5.0，显示浏览器实际配置的快捷键。
- 页面操作进行时禁用重复点击；失败信息留在界面中，状态同步可恢复排除站点和总开关对应的禁用状态。
- 阅读方式在一次配置写入中同步默认模式与最近使用模式。文本框支持 Ctrl+Enter，段落重试支持回车与空格。
- 设置开关保存失败后恢复原值；数字控件校验范围。保存提示在写入成功后显示，失败提示持续到后续成功保存。
- 设置页保留当前栏目，全部七个栏目在 640px 宽度下检查整体横向溢出。页面中的大型列表可以在各自容器内滚动。
- 对照面板关闭操作会还原当前页面，防止后续动态内容使面板意外重新出现。

## 运行开销

基线使用同一仓库 v1.4.0 提交 af02e4a，新版本加载当前目录。两次测试各用独立的临时 Edge 配置，合成 1800 段可读文本并连续改写其中一个段落 5 次。术语结果在本地命中，以隔离翻译网络延迟。通过 CDP 计数内容脚本的样式读取和 TreeWalker，并读取页面 Performance 指标。

| 指标 | v1.4.0 | v1.5.0 |
| --- | --- | --- |
| 五次局部修改的 getComputedStyle 调用 | 9055 | 60 |
| 五次局部修改的扫描次数 | 5 | 5 |
| 测量窗口内页面 TaskDuration 增量 | 203 ms | 50 ms |
| 测量结束时页面 JS 堆 | 11.13 MiB | 6.61 MiB |
| 三次编辑区输入触发的扫描 | 3 | 0 |
| 页面静置 1 秒触发的扫描 | 0 | 0 |

新版本多次同场景测得 TaskDuration 增量为 46–53 ms、页面 JS 堆为 6.61–8.81 MiB。以上时间与 JS 堆是合成页面的单机测量，实际网站的 DOM、脚本与系统负载会影响结果。JS 堆包含该测试页面脚本，浏览器进程内存还有其他组成部分。

- 扫描按变更文本块合并调度，最多保留 32 个待扫描范围，较广范围变化回退为全页扫描。
- 后台标签页积累变更，返回可见状态再处理。翻译还原后拆除翻译观察器与定时器。
- 弹窗状态通过页面连接推送，空闲 1.4 秒测试中没有状态轮询或额外后台消息。页面重新加载后按浏览器事件重连。
- 懒加载、重试和动态段落翻译共用当前页面会话的队列，避免滚动触发多个段落翻译流程并行。
- 离屏段落改为静态占位，移除每段常驻旋转和进度条扫光。
- 页面文本复用缓存的字符串体积按 2 MiB 预算淘汰，会话缓存仍按原有容量预算限制。该预算计算缓存字符串，其他 DOM 和 JavaScript 对象也会占用内存。
- 会话缓存按 1 秒窗口合并写入，20 次连续 store 的单元测试只产生 1 次 session 写入；并发清空测试仍通过。

## 回归范围

`npm run verify` 验证语法、配置迁移、模式一致性、请求边界、缓存合并写入与并发清空。`npm run test:edge` 保留上一版的动态补译、长文、异常响应、四种模式、还原和隐私隔离测试，并增加以下检查。

- 弹窗默认高度不超过 600px，文本和服务详情默认收起。
- Ctrl+Enter 文本翻译、实际版本显示和空闲状态推送。
- 从其他界面暂停后，弹窗总开关和主按钮及时同步。
- 保存失败提示与开关回滚，非法数字拒绝写入，成功保存后清除错误状态。
- 设置栏目重新加载后保留，640px 窄窗口布局检查。

测试使用临时空浏览器配置、合成网页、本机模拟接口和固定测试密钥。云端服务的实际翻译质量与账户额度需要相应账户验证。正文翻译仍会把待译文本提交给配置的服务，网页编辑区过滤与可信存储隔离沿用现有机制。

## 复现命令

```bash
npm run verify
npm install --no-save --package-lock=false playwright-core
npm run test:edge
npm run test:performance
```

性能脚本支持通过 EXTENSION_UNDER_TEST 指向解出的基线目录，使用 --baseline 参数允许旧版的全页扫描行为。更新已安装插件时，需要在 edge://extensions/ 重新加载，再刷新已有网页。
